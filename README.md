# Holdout — playtest build

A browser first-person shooter. Open the page, click to start, and play with mouse and keyboard.

- Modes: Holdout (waves) and Team Deathmatch
- Maps: The City, Forest Lake, Mountain Village
- Best in Chrome or Edge on a computer with a graphics card. If it runs slowly, set Quality to Low in Settings.

Credits: gun recordings from The Free Firearm Sound Library (public domain). Menu music played on the FluidR3 GM SoundFont by Frank Wen.
